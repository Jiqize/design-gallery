# Design System — Swiss Minimalism

## Aesthetic Vision
Swiss Minimalism emphasizes clarity, order, and precise typography. Neutral base with high-contrast accent colors, strict grid structure, generous whitespace, and sans-serif typography.

## Color Palette
- `--bg-primary`: `#FFFFFF`
- `--bg-secondary`: `#F4F4F6`
- `--text-main`: `#111111`
- `--text-muted`: `#666666`
- `--accent-red`: `#FF3333`
- `--border-color`: `#E5E5E7`

## Typography
- Font Family: `Inter, -apple-system, BlinkMacSystemFont, "SF Pro Text", sans-serif`
- Headings: Bold, negative letter-spacing (`-0.03em`), strict scale (36px, 24px, 18px, 14px)
- Body: 14px/1.6, clean line height

## Layout & Principles
- Radius: `4px` crisp edges
- Shadow: Crisp 1px border with minimal elevation
- Spacing: 8px base grid (8px, 16px, 24px, 48px)
