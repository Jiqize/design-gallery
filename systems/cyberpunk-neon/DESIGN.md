# Design System — Cyberpunk Neon

## Aesthetic Vision
Dark background with glowing neon accents, high-contrast futuristic UI components, glassmorphism, and bold monospace headings.

## Color Palette
- Base Dark: `#0D0D11`
- Surface: `#16161F`
- Neon Pink: `#FF0055`
- Cyber Cyan: `#00F0FF`
- Neon Yellow: `#FFE600`
- Text Light: `#F0F0F5`

## Typography
- Headings: `Orbitron, "JetBrains Mono", monospace`
- Body: `Inter, sans-serif`
